# Notices

This package curates theme JSON files from MIT-licensed Pi theme packages, upstream palette files, and local Catppuccin work.

Sources:

- Catppuccin: local `pi-catppuccin`, based on the official Catppuccin palette.
- Everforest: `pi-everforest` — https://github.com/angribot/pi-everforest
- Flexoki: `pi-theme-flexoki` — https://github.com/markacianfrani/pi-theme-flexoki
- Gruvbox: `@smoose/pi-themes` — https://github.com/smoosex/pi-themes
- Additional Gruvbox variants, Kanagawa Dragon, Tokyo Night Moon: `base16-schemes` / tinted-theming palettes — https://github.com/tinted-theming/schemes
- Hackerman: `@javiportillo/pi-hackerman` — https://github.com/javierportillo/pi-hackerman
- Kanagawa: `pi-kanagawa`
- Gruvbox Material, Matte Black, Miasma: `@victor-software-house/pi-curated-themes` — https://github.com/victor-software-house/pi-curated-themes
- Nord: `@spences10/pi-themes` — https://github.com/spences10/my-pi/tree/main/packages/pi-themes
- Rosé Pine: `lulucatdev/pi-themes` — https://github.com/lulucatdev/pi-themes
- Tokyo Night: `@wishx127/pi-tokyo-night` — https://github.com/wishx127/pi-tokyo-night
- Tokyo Night Storm: `@mammothb/pi-tokyonight-storm`
- Ethereal, Lumon, Osaka Jade, Retro 82, Vantablack, White: Omarchy built-in theme palettes — https://github.com/basecamp/omarchy
- Ristretto: Helix Monokai Pro Ristretto palette — https://github.com/helix-editor/helix/blob/master/runtime/themes/monokai_pro_ristretto.toml
